## Before you install

This app drives Proton's own `proton-drive` command-line tool, which it does not install. Install
it from <https://proton.me/drive/download> and run `proton-drive auth login` before you install
this app.

## Install

The install commands for Fedora, Ubuntu, Debian and Arch are on the packages page:
<https://osirison.github.io/proton-drive-sync-engine/distribution/packages/>.

Every file below has its SHA-256 in `SHA256SUMS`. After downloading the files you want into one
directory, `sha256sum --ignore-missing -c SHA256SUMS` checks them.
